### 1. test-requirement 单元测试

#### TC-REQ-001: 分析登录需求
**输入**:
```
分析以下登录需求的可测试性：
"用户可以使用手机号或邮箱登录，密码长度 8-20 位"
```

**预期输出**:
- 功能需求：手机号登录、邮箱登录、密码验证
- 测试条件：至少 4 个（有效手机号、有效邮箱、密码边界、密码超限）
- 需求缺陷：未说明密码复杂度、未说明错误处理

**验收标准**:
- [ ] 识别出所有功能需求
- [ ] 创建至少 4 个测试条件
- [ ] 识别出至少 2 个需求缺陷
