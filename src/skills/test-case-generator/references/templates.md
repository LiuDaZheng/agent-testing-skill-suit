# 测试用例模板库

## 标准测试用例模板

### 模板 1: 功能测试用例

```markdown

### 基本信息
- **模块**: [功能模块名称]
- **优先级**: P0/P1/P2
- **类型**: 正向/负向
- **测试技术**: [等价类/边界值/判定表等]

### 前置条件
- [条件 1]
- [条件 2]

### 测试数据
| 数据项 | 值 | 说明 |
|--------|-----|------|
| [字段 1] | [值] | [说明] |

### 测试步骤
| 步骤 | 操作 | 预期结果 |
|------|------|---------|
| 1 | [操作描述] | [预期结果] |
| 2 | [操作描述] | [预期结果] |
| 3 | [操作描述] | [预期结果] |

### 预期结果
[总体预期结果描述]

### 后置处理
- [清理操作]
```

## 测试数据模板

```markdown
# 测试数据清单

## 有效数据

| 数据 ID | 用途 | 数据内容 | 说明 |
|--------|------|---------|------|
| DATA-001 | 登录测试 | phone: 13800138000, code: 123456 | 有效用户 |
| DATA-002 | 搜索测试 | keyword: iPhone | 有效关键词 |

## 无效数据

| 数据 ID | 用途 | 数据内容 | 预期结果 |
|--------|------|---------|---------|
| DATA-INV-001 | 登录测试 | phone: 1380013800 | 手机号格式错误 |
| DATA-INV-002 | 登录测试 | phone: 1380013800a | 手机号格式错误 |

## 边界数据

| 数据 ID | 用途 | 数据内容 | 边界位置 |
|--------|------|---------|---------|
| DATA-Boundary-001 | 密码测试 | 5 位密码 | min-1 |
| DATA-Boundary-002 | 密码测试 | 6 位密码 | min |
| DATA-Boundary-003 | 密码测试 | 20 位密码 | max |
| DATA-Boundary-004 | 密码测试 | 21 位密码 | max+1 |

## 特殊数据

| 数据 ID | 用途 | 数据内容 | 说明 |
|--------|------|---------|------|
| DATA-Special-001 | 输入测试 | null | 空值 |
| DATA-Special-002 | 输入测试 | "" | 空字符串 |
| DATA-Special-003 | 输入测试 | <script>alert(1)</script> | XSS 攻击 |
| DATA-Special-004 | 输入测试 | ' OR '1'='1 | SQL 注入 |
```
