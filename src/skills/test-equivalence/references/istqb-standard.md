# ISTQB 等价类划分标准

## 官方定义

根据 ISTQB Foundation Level Syllabus，等价类划分 (Equivalence Class Partitioning, ECP) 是：

> 一种黑盒测试设计技术，其测试用例设计为执行来自等价类的输入/输出值。等价类是从规格说明中导出的输入或输出域的子集，其行为应相同。

## 核心原理

### 等价类划分原则

1. **完备性**：所有可能的输入都必须属于某个等价类
2. **互斥性**：每个输入只能属于一个等价类
3. **代表性**：类中任意值的行为应相同

### 测试用例数量

对于 n 个输入条件，每个条件有 v 个有效类和 i 个无效类：

```
最小测试用例数 = max(有效类数量, 无效类数量)
理想测试用例数 = 有效类覆盖 + 无效类单独测试
```

**注意**：无效类通常单独测试，避免多个无效条件掩盖彼此的错误。

### 有效 vs 无效等价类

| 特征 | 有效等价类 | 无效等价类 |
|------|-----------|-----------|
| 定义 | 符合需求的输入 | 不符合需求的输入 |
| 目的 | 验证正常功能 | 验证错误处理 |
| 数量 | 通常较少 | 通常较多 |
| 测试优先级 | 高 | 更高 (易发现缺陷) |

## 划分方法

### 1. 基于范围划分

```
输入：整数 x，范围 [1, 100]

有效类: [1, 100]
无效类 1: x < 1
无效类 2: x > 100
无效类 3: x 非整数
```

### 2. 基于集合划分

```
输入：颜色 {红，绿，蓝}

有效类：{红}, {绿}, {蓝}
无效类：其他任何值
```

### 3. 基于布尔值划分

```
输入：标志位 flag

有效类 1: flag = true
有效类 2: flag = false
无效类：非布尔值
```

### 4. 基于格式划分

```
输入：邮箱地址

有效类：符合 email 格式 (user@domain.com)
无效类 1：无 @ 符号
无效类 2：无域名
无效类 3：含非法字符
无效类 4：空值
```

## 测试用例设计步骤

### 步骤 1: 识别输入条件

从需求规格中提取所有输入：
```
功能：用户注册
输入条件:
  - 用户名 (字符串，5-20 字符)
  - 密码 (字符串，8-20 字符，含字母数字)
  - 邮箱 (字符串，email 格式)
  - 年龄 (整数，18-60)
```

### 步骤 2: 为每个条件划分等价类

```
用户名:
  有效：长度 [5, 20]
  无效：长度 <5, 长度 >20, 含特殊字符, 空值

密码:
  有效：长度 [8, 20] 且含字母数字
  无效：长度 <8, 长度 >20, 无字母，无数字，空值

邮箱:
  有效：符合 email 格式
  无效：格式错误，空值

年龄:
  有效：[18, 60]
  无效：<18, >60, 非整数，空值
```

### 步骤 3: 编号等价类

```
有效类:
  V1: 用户名有效
  V2: 密码有效
  V3: 邮箱有效
  V4: 年龄有效

无效类:
  I1: 用户名长度 <5
  I2: 用户名长度 >20
  I3: 密码长度 <8
  I4: 密码长度 >20
  I5: 邮箱格式错误
  I6: 年龄 <18
  I7: 年龄 >60
  ...
```

### 步骤 4: 设计测试用例

**覆盖有效类** (组合覆盖):
```
TC-01: V1 + V2 + V3 + V4 → 注册成功
```

**覆盖无效类** (单独测试):
```
TC-02: I1 + V2 + V3 + V4 → 错误：用户名太短
TC-03: V1 + I3 + V3 + V4 → 错误：密码太短
TC-04: V1 + V2 + I5 + V4 → 错误：邮箱格式错误
...
```

## 常见陷阱

### 1. 类划分过粗

```
错误做法:
  有效类：[1, 100]
  无效类：其他

正确做法:
  有效类：[1, 100]
  无效类 1: x < 1
  无效类 2: x > 100
  无效类 3: x 非数值
```

### 2. 遗漏无效类

```
常见遗漏:
  - 空值/null
  - 非预期类型 (字符串 vs 数字)
  - 特殊字符
  - 边界外的极端值
```

### 3. 无效类组合测试

```
错误：同时测试多个无效条件
  输入：用户名="" AND 密码="" AND 年龄=-1
  问题：无法确定哪个错误先被检测

正确：每次只测试一个无效条件
  TC-01: 用户名="" (其他有效)
  TC-02: 密码="" (其他有效)
  TC-03: 年龄=-1 (其他有效)
```
