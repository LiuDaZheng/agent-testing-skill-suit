# 等价类表 (Equivalence Class Table)

## 通用模板

### 单输入条件等价类表

| 输入条件 | 有效等价类 | 无效等价类 |
|----------|-----------|-----------|
| 描述 | 编号 + 描述 | 编号 + 描述 |
| 代表值 | 从每个有效类选 1-2 个 | 从每个无效类选 1 个 |

## 常见场景等价类表

### 场景 1: 年龄验证 (18-60 岁)

| 输入条件 | 有效等价类 | 无效等价类 |
|----------|-----------|-----------|
| 年龄 (整数) | V1: [18, 60] | I1: <18 |
| | | I2: >60 |
| | | I3: 非整数 |
| | | I4: 空值 |

**代表值**:
| 类 | 代表值 | 预期结果 |
|----|--------|----------|
| V1 | 25, 40 | 接受 |
| I1 | 17, 5 | 拒绝 - 年龄太小 |
| I2 | 61, 100 | 拒绝 - 年龄太大 |
| I3 | "abc", 18.5 | 拒绝 - 类型错误 |
| I4 | null, "" | 拒绝 - 必填 |

## 等价类检查清单

使用 ECP 时，请确认：

- [ ] 已识别所有输入条件
- [ ] 每个条件都划分了有效类
- [ ] 每个条件都划分了无效类
- [ ] 无效类覆盖：空值、类型错误、范围外、格式错误
- [ ] 每个类都有代表值
- [ ] 有效类可以组合测试
- [ ] 无效类单独测试
- [ ] 已记录每个类的预期结果

## 与 BVA 结合使用

```
完整测试设计流程:

1. ECP 划分等价类
   ↓
2. 从每个类选代表值
   ↓
3. BVA 补充边界值 (min-1, min, min+1, max-1, max, max+1)
   ↓
4. 合并去重
   ↓
5. 设计测试用例
   ↓
6. 执行并记录
```
