# 测试设计技术详解

## 黑盒测试技术

### 1. 等价类划分（Equivalence Partitioning）

**原理**：将输入域划分为若干等价类，从每个类中选择代表性数据。

**步骤**：
1. 识别输入条件
2. 划分有效等价类（符合需求的输入）
3. 划分无效等价类（不符合需求的输入）
4. 从每个等价类选择代表性数据

**示例**：手机号输入（11 位数字）
| 等价类 | 描述 | 示例数据 |
|--------|------|----------|
| 有效 | 11 位有效手机号 | 13800138000 |
| 无效 - 长度不足 | <11 位 | 1380013800 |
| 无效 - 长度超限 | >11 位 | 138001380001 |
| 无效 - 非数字 | 包含字母 | 1380013800a |

### 2. 边界值分析（Boundary Value Analysis）

**原理**：缺陷常出现在输入域的边界处。

**步骤**：
1. 识别边界点
2. 测试边界值、边界+1、边界 -1

**示例**：密码长度 8-20 位
| 测试点 | 输入长度 | 预期 |
|--------|----------|------|
| 边界下 -1 | 7 位 | 拒绝 |
| 边界下 | 8 位 | 接受 |
| 边界上 | 20 位 | 接受 |
| 边界上 +1 | 21 位 | 拒绝 |

### 3. 决策表测试（Decision Table Testing）

**原理**：适用于多条件组合场景。

**步骤**：
1. 识别所有条件（输入）
2. 识别所有动作（输出）
3. 生成所有规则组合
4. 简化决策表（合并相似规则）

**示例**：登录验证（用户名、密码、验证码）
- 3 个条件，每个 2 种状态（有效/无效）
- 2³ = 8 条规则

### 4. 状态转换测试（State Transition Testing）

**原理**：适用于有状态变化的系统。

**步骤**：
1. 识别所有状态
2. 识别状态间的转换
3. 识别触发转换的事件
4. 设计覆盖所有转换的测试用例

**示例**：订单状态
```
待支付 → 已支付 → 已发货 → 已完成
   ↓         ↓
 取消      退款
```

## 白盒测试技术

### 1. 语句覆盖（Statement Coverage）

**目标**：每行代码至少执行一次。

**示例**：
```python
if condition_a:  # 需要测试 True
    do_something()
if condition_b:  # 需要测试 True
    do_other_thing()
```
最少用例数：2（覆盖所有语句）

### 2. 分支覆盖（Branch Coverage）

**目标**：每个分支的 True/False 都执行一次。

**示例**：
```python
if condition_a:
    do_something()
else:
    do_other_thing()
```
最少用例数：2（True 和 False 各一次）

### 3. 路径覆盖（Path Coverage）

**目标**：覆盖所有可能的执行路径。

**示例**：
```python
if A:
    if B:
        do_X()
    else:
        do_Y()
else:
    do_Z()
```
路径数：3（A&B, A&!B, !A）

## 经验驱动技术

### 1. 探索性测试（Exploratory Testing）

**适用场景**：
- 需求不完整
- 时间紧迫
- 发现隐藏缺陷

**方法**：
- 设定测试章程（Test Charter）
- 时间盒（Time-box）测试
- 记录发现和思路

### 2. 错误推测（Error Guessing）

**原理**：基于经验推测可能出错的地方。

**常见错误点**：
- 除零错误
- 空指针/空值处理
- 边界条件
- 并发问题
- 资源泄漏

### 3. 检查表测试（Checklist-based Testing）

**适用场景**：
- 回归测试
- 合规性测试
- 发布前检查

**示例检查表**：
- [ ] 所有高优先级用例已执行
- [ ] 严重缺陷已修复
- [ ] 性能指标达标

## 技术选择指南

| 场景 | 推荐技术 |
|------|----------|
| 输入域明确 | 等价类划分、边界值分析 |
| 多条件组合 | 决策表测试 |
| 状态流转 | 状态转换测试 |
| 代码审查 | 白盒测试 |
| 时间紧迫 | 探索性测试、错误推测 |
| 回归测试 | 检查表测试 |
