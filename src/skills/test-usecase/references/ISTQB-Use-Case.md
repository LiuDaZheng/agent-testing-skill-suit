# ISTQB 用例场景测试技术参考

## 官方定义 (ISTQB CTFL Syllabus)

**用例场景测试 (Use Case Testing)**: 一种黑盒测试技术，测试用例设计用于执行用户场景。

### 测试基础
- 基于用例文档
- 关注用户与系统的交互
- 覆盖端到端流程

## 用例元素

### 核心组件

```
┌─────────────────────────────────────────┐
│              用例 (Use Case)            │
├─────────────────────────────────────────┤
│  • 用例名称和 ID                         │
│  • 参与者 (Actors)                       │
│  • 前置条件 (Preconditions)              │
│  • 后置条件 (Postconditions)             │
│  • 主成功场景 (Main Success Scenario)    │
│  • 扩展场景 (Extensions/Alternative)     │
│  • 异常场景 (Exceptions)                 │
│  • 业务规则 (Business Rules)             │
│  • 特殊需求 (Special Requirements)       │
└─────────────────────────────────────────┘
```

### 参与者类型
- **主要参与者**: 发起用例的用户
- **次要参与者**: 支持用例完成的外部系统
- **旁观参与者**: 关心用例结果但不直接参与

## 场景类型

### 1. 主成功场景 (Basic Flow)
- 理想路径
- 无异常和分支
- 达成用户目标
- 每个用例只有一个

### 2. 扩展场景 (Alternative Flow)
- 有效的替代路径
- 处理业务分支
- 仍达成目标 (可能方式不同)
- 可能有多个

### 3. 异常场景 (Exception Flow)
- 错误处理路径
- 目标未达成
- 系统优雅降级
- 可能有多个

## 场景编号约定

```
主场景：1, 2, 3, 4, 5...

扩展场景：
  3a: 步骤 3 的第一个扩展
  3b: 步骤 3 的第二个扩展
  5a1: 步骤 5 的第一个扩展的子步骤 1

示例:
  1. 用户登录
  2. 用户搜索商品
  3. 用户添加到购物车
     3a. 商品已售罄
         3a1. 显示缺货通知
         3a2. 推荐类似商品
  4. 用户结算
     4a. 使用新地址
  5. 用户支付
     5a. 支付失败
```

## 测试用例设计

### 从场景到测试用例

```
每个场景 → 至少一个测试用例

主成功场景:
  - 验证正常流程
  - 验证后置条件

扩展场景:
  - 验证分支逻辑
  - 验证系统响应

异常场景:
  - 验证错误处理
  - 验证系统稳定性
```

### 测试用例模板

```markdown
# 测试用例：TC-{用例 ID}-{场景编号}

## 基本信息
- **关联用例**: UC-XXX
- **场景**: 主成功场景 / 扩展场景 Xa
- **优先级**: 高/中/低

## 测试步骤
1. [前置条件设置]
2. [执行步骤 1]
3. [执行步骤 2]
...

## 测试数据
- 输入数据: ...
- 预期数据: ...

## 预期结果
- [结果 1]
- [结果 2]
...

## 后置条件验证
- [验证点 1]
- [验证点 2]
```

## 覆盖率计算

### 场景覆盖率
```
场景覆盖率 = 已测试场景数 / 总场景数 × 100%

目标：100% (所有场景都测试)
```

### 用例覆盖率
```
用例覆盖率 = 已测试用例数 / 总用例数 × 100%

目标：100% (所有用例都测试)
```

### 路径覆盖率
```
路径覆盖率 = 已测试路径数 / 总路径数 × 100%

更严格：覆盖所有可能的场景组合
```

## 质量属性检查

### 用例质量
- [ ] 名称清晰描述目标
- [ ] 参与者明确
- [ ] 前置条件可验证
- [ ] 后置条件可验证
- [ ] 主场景步骤完整
- [ ] 扩展场景覆盖分支
- [ ] 异常场景处理错误

### 测试用例质量
- [ ] 步骤可执行
- [ ] 数据可准备
- [ ] 结果可验证
- [ ] 独立可运行
- [ ] 可重复执行
