# ISTQB 边界值分析标准

## 官方定义

根据 ISTQB Foundation Level Syllabus，边界值分析 (Boundary Value Analysis, BVA) 是：

> 一种黑盒测试设计技术，其测试用例设计为执行来自等价类边界的输入/输出值。

## 核心原理

### 边界值选择规则

对于 n 变量函数，BVA 测试用例数量为 **4n + 1** (标准 BVA) 或 **6n** (健壮 BVA)

**标准 BVA (单缺陷假设)**:
- 每次只让一个变量取边界值
- 其他变量取正常值 (nominal value)

**健壮 BVA (多缺陷假设)**:
- 考虑无效边界 (超出范围)
- 测试 min-1 和 max+1

### 边界值集合

对于范围 [min, max]：

| 类型 | 值 | 说明 |
|------|-----|------|
| 无效下界 | min-1 | 刚好低于最小值 |
| 有效下界 | min | 最小值本身 |
| 有效下界 +1 | min+1 | 刚好高于最小值 |
| 有效上界 -1 | max-1 | 刚好低于最大值 |
| 有效上界 | max | 最大值本身 |
| 无效上界 | max+1 | 刚好高于最大值 |

## 与等价类划分的关系

```
等价类划分 (ECP)          边界值分析 (BVA)
     ↓                          ↓
  分组输入                   测试边界
     ↓                          ↓
  每组选代表值              边界处选极值
     ↓                          ↓
     └─────────→ 结合使用 ←─────────┘
```

**最佳实践**：
1. 先用 ECP 识别有效/无效等价类
2. 再用 BVA 确定每个类的边界值
3. 设计测试用例覆盖所有边界

## 测试用例设计步骤

### 步骤 1: 识别输入条件

列出所有输入参数及其约束：
```
输入：年龄 (整数)
约束：18 ≤ 年龄 ≤ 60
```

### 步骤 2: 确定等价类

```
有效等价类：[18, 60]
无效等价类 1: (-∞, 17]
无效等价类 2: [61, +∞)
```

### 步骤 3: 识别边界

```
下边界：17, 18, 19
上边界：59, 60, 61
```

### 步骤 4: 设计测试用例

```
TC-01: 输入=17, 预期=无效
TC-02: 输入=18, 预期=有效
TC-03: 输入=19, 预期=有效
TC-04: 输入=59, 预期=有效
TC-05: 输入=60, 预期=有效
TC-06: 输入=61, 预期=无效
```

## 常见边界类型

### 1. 数值边界
- 整数范围：min, max
- 小数精度：0.01, 99.99
- 负数：-100, -1, 0, 1, 100

### 2. 字符串边界
- 长度：0 (空), 1, max_length, max_length+1
- 字符类型：ASCII, Unicode, 特殊字符

### 3. 集合边界
- 元素数量：0, 1, max_count, max_count+1
- 列表：空列表，单元素，满列表

### 4. 时间边界
- 日期：开始日期，结束日期
- 时间：00:00, 23:59
- 超时：timeout-1, timeout, timeout+1
