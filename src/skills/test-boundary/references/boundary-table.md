# 边界值表 (Boundary Value Table)

## 通用边界值模板

### 单变量范围 [min, max]

| 测试点 | 值 | 类型 | 预期结果 |
|--------|-----|------|----------|
| 无效下界 | min-1 | 无效 | 拒绝/错误 |
| 有效下界 | min | 有效 | 接受 |
| 有效下界 +1 | min+1 | 有效 | 接受 |
| 中间值 | (min+max)/2 | 有效 | 接受 |
| 有效上界 -1 | max-1 | 有效 | 接受 |
| 有效上界 | max | 有效 | 接受 |
| 无效上界 | max+1 | 无效 | 拒绝/错误 |

## 边界值检查清单

- [ ] 已识别所有输入参数的范围

- [ ] 已计算 min-1, min, min+1, max-1, max, max+1
- [ ] 已考虑空值/零值/null 等特殊情况
- [ ] 已考虑多变量组合的边界
- [ ] 已记录每个边界值的预期结果
