# 缺陷报告模板

## 标准模板

```markdown
## 缺陷 ID: BUG-[模块]-[编号]

### 基本信息
| 字段 | 值 |
|------|-----|
| 缺陷 ID | BUG-LOGIN-001 |
| 标题 | [简明描述问题] |
| 模块 | [受影响模块] |
| 子模块 | [可选] |
| 发现版本 | v1.2.0 |
| 发现日期 | 2024-01-15 |
| 发现人 | 张三 |

### 严重程度与优先级
| 字段 | 值 | 说明 |
|------|-----|------|
| 严重程度 | Critical/Major/Minor/Trivial | 对系统的影响 |
| 优先级 | High/Medium/Low | 修复的紧急程度 |

### 重现步骤
1. [步骤 1 - 尽可能详细]
2. [步骤 2 - 包含具体数据]
3. [步骤 3 - 包含点击、输入等操作]
4. ...

### 预期结果
[描述应该发生什么，引用需求文档如适用]

### 实际结果
[描述实际发生了什么，包含错误信息]

### 环境信息
| 项目 | 值 |
|------|-----|
| 操作系统 | Windows 10 / macOS 14 / Linux |
| 浏览器 | Chrome 120 / Firefox 121 |
| 应用版本 | v1.2.0 |
| 设备 | iPhone 15 / 华为 Mate 60（如适用） |
| 网络 | WiFi / 4G / 5G（如适用） |

### 测试数据
- 账号：test_user_001
- 输入数据：[具体数据]
- 前置条件：[如用户已登录]

### 附件
- [ ] 截图（标注问题位置）
- [ ] 录屏（动态问题）
- [ ] 日志文件（错误日志、控制台日志）
- [ ] 接口请求/响应（API 问题）

### 缺陷状态
| 字段 | 值 |
|------|-----|
| 状态 | Open / In Progress / Fixed / Verified / Closed / Rejected / Deferred |
| 指派给 | [开发人员姓名] |
| 解决版本 | [计划修复的版本] |
| 解决日期 | [实际修复日期] |
| 解决人 | [开发人员姓名] |

### 备注
- [补充说明、特殊注意事项]
```

## 严重程度定义

| 等级 | 定义 | 示例 |
|------|------|------|
| **Critical** | 系统崩溃、数据丢失、核心功能完全不可用 | 应用无法启动、数据库崩溃 |
| **Major** | 主要功能失效，无 workaround | 支付失败、登录失败 |
| **Minor** | 次要功能问题，有 workaround | 某个按钮点击无响应但功能可用 |
| **Trivial** | UI 问题、文案错误、建议性改进 | 字体大小不一致、错别字 |

## 优先级定义

| 等级 | 定义 | 响应时间 |
|------|------|----------|
| **High** | 阻碍发布、影响大量用户 | 24 小时内 |
| **Medium** | 影响部分功能，可短期 workaround | 3 个工作日内 |
| **Low** | 轻微问题，可延期修复 | 下个版本 |

## 缺陷报告最佳实践

### DO（推荐）
- ✅ 标题简明扼要（<50 字）
- ✅ 重现步骤清晰、可重复
- ✅ 包含预期结果和实际结果
- ✅ 附上截图/日志等证据
- ✅ 标注环境信息
- ✅ 严重程度和优先级合理

### DON'T（避免）
- ❌ 标题模糊（如"系统有问题"）
- ❌ 步骤不完整、无法重现
- ❌ 缺少预期结果
- ❌ 无截图或日志
- ❌ 多个问题混在一个报告中
- ❌ 情绪化语言（如"这个 bug 很严重"）

## 缺陷报告示例

```markdown
## 缺陷 ID: BUG-PAY-015

### 基本信息
- 标题：支付宝支付成功后订单状态未更新
- 模块：订单管理
- 发现版本：v1.2.0
- 发现日期：2024-01-15
- 发现人：张三

### 严重程度与优先级
- 严重程度：Major
- 优先级：High

### 重现步骤
1. 登录账号 test_user_001
2. 选择商品"测试商品"，点击"立即购买"
3. 选择支付方式"支付宝"
4. 完成支付宝支付
5. 返回订单列表查看订单状态

### 预期结果
订单状态显示为"已支付"

### 实际结果
订单状态仍为"待支付"

### 环境信息
- OS: iOS 17.2
- 应用版本：v1.2.0
- 设备：iPhone 15 Pro

### 附件
- 截图：order_status.png
- 日志：payment_log.txt
```
