# 测试执行检查清单

## 执行前检查

### 环境准备
- [ ] 测试环境已部署（版本正确）
- [ ] 数据库连接正常
- [ ] 第三方服务可访问（如支付、短信）
- [ ] 测试账号已准备
- [ ] 测试数据已导入

### 冒烟测试
- [ ] 应用可正常启动
- [ ] 核心功能可用（登录、主流程）
- [ ] 关键接口可访问
- [ ] 无阻塞性缺陷

### 测试用例准备
- [ ] 测试用例已评审
- [ ] 测试数据已关联
- [ ] 自动化脚本可运行
- [ ] 优先级已标注

### 工具准备
- [ ] 缺陷管理系统已配置
- [ ] 截图/录屏工具就绪
- [ ] 日志收集工具就绪
- [ ] 接口测试工具就绪（Postman 等）

## 执行中检查

### 测试执行
- [ ] 按优先级执行（High → Medium → Low）
- [ ] 记录每个用例的执行结果
- [ ] 失败用例记录详细原因
- [ ] 阻塞用例标注依赖缺陷

### 缺陷报告
- [ ] 缺陷标题清晰
- [ ] 重现步骤完整
- [ ] 预期/实际结果明确
- [ ] 附件齐全（截图、日志）
- [ ] 严重程度/优先级合理
- [ ] 指派给正确负责人

### 进度跟踪
- [ ] 每日更新执行进度
- [ ] 记录阻塞问题
- [ ] 及时上报风险

## 执行后检查

### 结果汇总
- [ ] 所有计划用例已执行
- [ ] 执行结果已统计（通过率）
- [ ] RTM 已更新执行状态
- [ ] 缺陷列表已汇总

### 缺陷跟踪
- [ ] 严重缺陷已修复验证
- [ ] 待修复缺陷已列出
- [ ] 延期缺陷已记录原因

### 报告编写
- [ ] 测试执行报告已完成
- [ ] 缺陷分析报告已完成
- [ ] 风险评估已更新

```markdown
- 已修复：[数量]
- 待验证：[数量]

### 风险问题
- [列出影响进度的问题]

- [列出工作内容]
```

## 回归测试检查清单

### 回归触发条件
- [ ] 缺陷修复后
- [ ] 代码变更后
- [ ] 环境变更后
- [ ] 发布前

### 回归范围
- [ ] 修复模块相关用例（100%）
- [ ] 关联模块用例（影响分析）
- [ ] 核心功能用例（全量）

### 回归执行
- [ ] 自动化回归已运行
- [ ] 手动回归已完成
- [ ] 回归结果已记录
